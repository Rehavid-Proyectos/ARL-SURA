# REHAVID · Portafolio comercial digital

Catálogo de apoyo al equipo comercial con 32 productos organizados en 7 líneas, 6 videos, infografías, herramientas y demostraciones interactivas.

Las fichas y la calculadora presentan horas estimadas de producción o adaptación. Cada propuesta requiere definir el alcance y validar sus valores comerciales.

El sitio estático se prepara con un índice, recursos multimedia y demostraciones. Las herramientas de ejemplo identifican expresamente sus datos simulados.
